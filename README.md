# port

## Manoj Kumar Portfolio

A responsive, static portfolio site for Manoj Kumar. It is built with plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Run locally

Open `index.html` in a browser, or use a local static-file server such as the VS Code Live Server extension.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.

The site entry point is kept at the repository root so GitHub Pages can serve it directly.
